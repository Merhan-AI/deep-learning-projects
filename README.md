## Projects

### 1. Pass/Fail Prediction :- Neural Network
- Predicts whether a student passes or fails
- Based on hours of study
- Built using a 3-layer neural network
- Achieved 100% accuracy after 1000 epochs
- Tools: Python, TensorFlow, Keras, NumPy

## Neural Network Architecture
- Input Layer: 1 neuron (hours studied)
- Hidden Layer 1: 8 neurons (ReLU)
- Hidden Layer 2: 4 neurons (ReLU)
- Output Layer: 1 neuron (Sigmoid)
